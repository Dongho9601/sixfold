Return to Sixfold

Rules, privacy, and credits

A free game

Sixfold is free and non-commercial. Gold is a game score with no monetary or material value. There are no advertisements, payments, donations, cash-out, or monetary or material prizes.

Each run starts with 100 Gold and lasts up to 100 rolls. The server draws outcomes and settles wagers. Only the final balance after roll 100 can enter the leaderboard; an earlier bankruptcy posts no score. Each anonymous player keeps their best completed score. The in-game How to play guide explains all targets, payouts, Tilt, Shake, Jackpot, and controls. Show probabilities is off at the start of every run. Turning it on requires confirmation and excludes that run’s score from the leaderboard, even if it is turned off later. Previous leaderboard records stay. The server saves the setting and exclusion with the run. Odds remain available through browser inspection.

Saved games and public names

A first-party session cookie identifies your anonymous player. Its maximum age is one year from creation. The server stores a hash of that cookie, a random player ID, your nickname, game balance, board probabilities, roll count, probability-display setting, run leaderboard eligibility, completed score, revision, last result, and receipts for accepted actions. The server retains player records and retry receipts indefinitely so saved games can continue and a repeated request cannot settle again. Clearing or losing the cookie does not delete that data, and there is no account recovery.

Your player ID, nickname, completed best score, and rank can appear publicly on the leaderboard. Choose a nickname that does not reveal private information. The operator can hide an abusive entry without deleting its game or score.

Browser storage and network data

Local browser storage holds sound, motion, and language preferences, guide dismissal, and three recent bet amounts. Tab session storage holds a pending action and its retry ID until the server confirms or rejects it. Draft wagers remain in the current tab and clear when the page reloads.

The application uses your IP address in memory to limit requests, without saving it to the game database. Limiter storage is bounded. Entries idle for 30 minutes become eligible for incremental cleanup as later requests arrive; remaining entries clear when the server process restarts. The application does not include analytics or third-party runtime requests, and does not log cookies, action bodies, or session identifiers. A hosting provider or reverse proxy may process IP addresses and request logs; its logging and retention settings must be reviewed by the operator before public hosting.

Credits and contact

The bundled die, board, icons, and favicon are CSS or SVG. Sound is generated locally with Web Audio. Fonts come from your operating system. No external artwork, fonts, recordings, or reference screenshots are fetched by the game.

The repository credits the roulette table layout at Casino.org and Balatro screenshots on PlayStation as design references; their assets are not bundled. The development tools include Vite (MIT), tsx (MIT), TypeScript (Apache-2.0), and Playwright (Apache-2.0), alongside Node.js and its bundled SQLite.

An operator contact for privacy requests and abusive-name reports has not yet been published.
