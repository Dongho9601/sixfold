# HLBM visual references

These two small PNGs are copied from the sibling `hold_less_be_more` repository's
generated pixel UI art for Rune Foundry's web HUD:

- `icon_gem.png` — Shards resource marker.
- `icon_seal.png` — Heart Seal contextual action marker.

The tetromino and field graphics remain procedural Canvas geometry so Rune Foundry has
no runtime dependency on the sibling repository or Unity metadata.
